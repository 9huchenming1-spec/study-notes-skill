# 学习笔记助手

一个将学习笔记整理成复习提纲的 AI skill。适合整理课堂记录、自学记录与学习复盘。

## 功能

- 归纳知识点，保留关键例子和原有疑问。
- 将补充解释与原笔记内容区分开。
- 保留公式、代码的适用前提与学习进度。
- 生成复习自测题和参考答案。

输入可以是粘贴的文字；附件需要所用 AI 工具具备相应读取能力。

## 项目文件

- [study-notes/SKILL.md](study-notes/SKILL.md)：skill 的名称、描述和工作规则。
- `outputs/`：本地试用生成的笔记，由 `.gitignore` 排除在版本管理之外。

## 本地试用

让 AI 读取 `study-notes/SKILL.md` 并按其中规则整理一段笔记。例如：

> 请按 study-notes/SKILL.md 的规则整理以下笔记：今天学了栈和队列。栈后进先出，队列先进先出。我还不明白为什么两个栈能实现一个队列。

检查输出是否忠实于输入、是否保留疑问，以及自测题是否能从笔记或明确标注的补充解释中找到答案。

当前验证方式为人工试用；笔记中的代码是否能运行，需要另行验证。
